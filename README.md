# 사용자공임 산출 계산기(M/H적용)

공임금액과 작업시간으로 시간당 공임단가(M/H)를 구하고, 기준금액과 적용율을 반영해 최종 사용자공임 금액을 자동으로 계산해주는 프로그램입니다.

## 프로그램 소개

자동차 정비 견적에서 "사용자공임"을 산출할 때, 공식 공임단가(시간당 M/H 단가)를 기준으로
기준금액과 추가 작업시간, 적용율(%)을 반영해 최종 금액을 계산해야 하는 경우가 있습니다.
이 프로그램은 그 계산 과정을 숫자만 입력하면 자동으로, 실시간으로 처리해줍니다.

인터넷 연결이나 별도 프로그램 설치, API 키 없이 완전히 오프라인으로 동작합니다.

## 주요 기능

- STEP 1: 공임금액 ÷ 시간 → 시간당 공임단가(H단가) 자동 계산
- STEP 2: 기준금액 + 여러 시간(H) 항목 합산 + 적용율(%)을 반영해 최종 결과값 계산
- 시간(H) 항목은 "+ 시간 추가" 버튼으로 필요한 만큼 추가/삭제 가능
- 입력값을 바꾸면 버튼 없이 즉시 재계산
- Windows 실행파일(.exe) 버전과 웹 브라우저(index.html) 버전 두 가지 제공

## 프로그램 동작 흐름

```
공임금액 / 시간 입력
        ↓
   H단가(시간당 공임단가) 자동 계산
        ↓
기준금액 / 시간(H) 항목들 / 적용율 입력
        ↓
   공임합계 = 기준금액 + (총 H × H단가)
        ↓
   최종 결과값 = 공임합계 × (적용율 ÷ 100)
```

## 실행 화면

STEP 1(H단가 계산) → STEP 2(기준금액·시간·적용율 입력) → 최종 결과값(진한 녹색 카드에
큰 글씨로 강조 표시, 아래에 H단가/총H/공임합계/적용율 검산값 표시) 순서로 구성된 화면입니다.
직접 실행해보면 바로 확인할 수 있습니다.

## 가장 쉬운 설치 방법

### 방법 1. 실행파일(exe) 사용 — 가장 간편함

1. 이 저장소의 [Releases](../../releases) 페이지로 이동
2. 최신 버전(v1.0.0) 선택
3. Assets에서 `사용자공임계산기.exe` 다운로드
4. 다운로드한 파일을 더블클릭해서 실행

Python이나 다른 프로그램을 설치할 필요가 없습니다.

### 방법 2. 웹 버전 사용

1. 이 저장소에서 `index.html` 파일을 다운로드 (Code → Download ZIP)
2. 압축을 풀고 `index.html`을 더블클릭해서 브라우저로 열기

## 개발자용 실행 방법

### 필요한 프로그램

- Windows 10/11
- Python 3.9 이상 (Windows용 공식 설치본에는 tkinter가 기본 포함되어 있습니다)

### 설치

이 프로그램은 Python 표준 라이브러리만 사용하므로 별도 패키지 설치가 필요 없습니다.
exe로 다시 빌드하고 싶을 때만 아래 도구가 필요합니다.

```bash
pip install pyinstaller
```

### 실행

```bash
python labor_calculator.py
```

### exe 다시 빌드하기

```bash
python -m PyInstaller --onefile --windowed --name "사용자공임계산기" labor_calculator.py
```

빌드 결과물은 `dist/` 폴더에 생성됩니다.

## 설정

이 프로그램은 API 키나 환경변수, 별도 설정 파일이 필요 없습니다. 모든 계산은 프로그램
내부에서만 이루어지며, 외부로 어떤 데이터도 전송하지 않습니다.

## 사용방법

1. STEP 1에서 공임금액과 시간을 입력하면 H단가(시간당 공임단가)가 자동으로 계산되어 표시됩니다.
2. STEP 2에서 기준금액을 입력합니다.
3. 시간(H) 항목에 값을 입력하고, 필요하면 "+ 시간 추가"로 항목을 더 추가합니다. 각 항목 옆의
   "×" 버튼으로 삭제할 수 있습니다.
4. 적용율(%)을 입력합니다.
5. 화면 하단에 최종 결과값과 계산 세부값(H단가/총H/공임합계/적용율)이 즉시 표시됩니다.

## 결과물 저장 위치

이 프로그램은 파일을 생성하거나 저장하지 않습니다. 화면에 표시되는 계산 결과를 확인하는
용도로만 사용합니다.

## 주의사항

- 계산 결과는 참고용이며, 실제 정비 견적이나 청구 금액과 다를 수 있습니다.
- 인터넷 연결 없이 동작하며, 어떤 개인정보나 입력값도 외부로 전송하지 않습니다.

## 문제 해결

**"Windows에서 PC를 보호했습니다" 경고가 뜨는 경우**
서명되지 않은 개인 배포 실행파일이라 Windows SmartScreen이 표시하는 정상적인 경고입니다.
"추가 정보" 클릭 → "실행" 버튼을 눌러 실행할 수 있습니다.

**실행이 안 되거나 바로 종료되는 경우**
백신 프로그램이 알 수 없는 실행파일을 차단했을 수 있습니다. 백신 프로그램에서 예외 처리
후 다시 실행해보세요.

**숫자가 이상하게 계산되는 경우**
입력 칸에 숫자와 쉼표(,) 외의 문자가 들어가지 않았는지 확인해주세요.
